# iDreamMusic integrated siteThis package starts with your existing static Muse site and now includes real Supabase-backed authentication and upload flows.## What is now integrated* Your original public-facing Muse site and subpages* Magic-link sign-in with Supabase Auth* Direct audio upload on every Muse page* All-Muse capture page at `/studio/capture`* Automatic creation of:  * `songs`  * `song\\\\\\\_stages`  * `song\\\\\\\_versions`  * `attachments`  * optional `writer\\\\\\\_notes`* Song detail pages with audio playback* Listener comments on song pages* Studio dashboard showing the signed-in user’s latest uploads* Blog approval queue for owner/manager roles## The publishing behavior* Writer notes are private by default, but the author can mark them public.* Blog posts are not public until approved by an `owner` or `manager`.* Muse uploads can be made public immediately by checking the “show this upload publicly” box.* Audio files are stored in the `song-assets` bucket and exposed with public playback URLs for easy Muse-page listening.## Local setup1. Unzip the project2. Copy `.env.example` to `.env.local`3. Add your Supabase values:```bashNEXT\\\\\\\_PUBLIC\\\\\\\_SUPABASE\\\\\\\_URL=...NEXT\\\\\\\_PUBLIC\\\\\\\_SUPABASE\\\\\\\_ANON\\\\\\\_KEY=...```4. Install packages:```bashnpm install```5. Start locally:```bashnpm run dev```If the env vars are missing, the public catalog still falls back to sample song data so you can inspect the UI.## Supabase setupRun these in the Supabase SQL editor, in this order:1. `supabase/migrations/0001\\\\\\\_idreammusic\\\\\\\_schema.sql`2. `supabase/seed.sql`If you already applied the earlier schema before this auth/upload pass, run:* `supabase/migrations/0002\\\\\\\_auth\\\\\\\_upload\\\\\\\_refresh.sql`That patch makes the song-assets bucket public for playback and fills in the full Muse/current taxonomy.## Promote your own account to site ownerAfter you sign in once and a profile row exists, run this in the Supabase SQL editor:```sqlupdate public.profilesset role = 'owner'where id = 'YOUR\\\\\\\_AUTH\\\\\\\_USER\\\\\\\_ID';```Then your account will see the review queue at `/admin/review`.## What to test first1. Sign in at `/auth/sign-in`2. Visit a Muse page such as `/muses/urania`3. Upload an MP3/WAV/audio file4. Confirm you land on `/songs/\\\\\\\[slug]`5. Leave a comment as a signed-in listener6. Check `/studio` to see your own latest uploads## Push to Vercel1. Push this folder to GitHub.2. Import the repo into Vercel.3. Add the two Supabase env vars in Vercel Project Settings.4. Redeploy.
